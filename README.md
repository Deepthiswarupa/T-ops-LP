# Talent Ops Landing Page

This repository contains the standalone, animated landing page for **Talent Ops**.

## Overview
It is built with React, Vite, Framer Motion, and Three.js to provide a rich, interactive experience demonstrating the core features of the Talent Ops platform.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Structure
- `src/landing`: Contains all sections, animations, and components for the landing page.
- `src/components/ui`: Shared UI components used across the landing page.
- `src/App.tsx`: The main entry point that sets up the React Router and renders the LandingPage component.
